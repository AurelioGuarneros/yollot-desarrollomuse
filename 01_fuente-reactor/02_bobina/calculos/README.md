# Cálculos de la bobina (Python)

Scripts chicos y verificables, uno por cálculo. Cada script imprime sus
supuestos (V, I, f, duty, núcleo) antes del resultado.

Pendientes de escribir, en este orden:
1. `vueltas_henrios.py` — N ↔ L a partir del AL de la ferrita.
2. `saturacion.py` — B a una corriente dada y margen contra Bsat.
3. `rizo_corriente.py` — ΔI = V·D/(L·f) y L necesaria para un rizo dado.
4. `energia.py` — E = ½·L·I² por ciclo y potencia a la frecuencia de trabajo.
